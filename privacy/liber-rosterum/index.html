Политика конфиденциальности

Дата вступления в силу: 19.11.2026

Разработчик: Кисин Игорь Евгеньевич, самозанятый, контакт: igorkisin@yandex.ru.

1. Общие положения. Политика описывает, какие данные обрабатывает приложение Liber Rosterum (Android, пакет com.medoedy.liber, и веб-версия rogienisick.github.io/liber-rosterum-web). Приложение бесплатное, без рекламы и без регистрации.

2. Что хранится только на устройстве. Ростеры, коллекция миниатюр, фотографии юнитов, закладки, ход текущей битвы и настройки сохраняются на вашем устройстве и нам не передаются (кроме случаев из п. 3 и п. 4). Удаление приложения удаляет эти данные.

3. Имя пользователя. Если включена настройка «Отправлять имя автору» (включена по умолчанию), автору в Telegram отправляется имя, которое вы ввели в приложении, случайный идентификатор установки (не связан с устройством), код поддержавшего вида LR-XXXXXX и версия приложения. Это нужно, чтобы знать число пользователей и выдавать статус поддержавшим. Настройку можно выключить в любой момент.

4. Статистика для автора (только с согласия). При первом запуске приложение спрашивает разрешение. Если вы нажали «Разрешить», автору в Telegram вместе с данными из п. 3 отправляются:

  • названия, фракции и размер ваших ростеров (при создании и одна сводка по уже созданным);
  • итоги завершённых битв: миссия, имена игроков и фракции, введённые в приложении, счёт, длительность;
  • список миниатюр в коллекции: название юнита, фракция, число моделей.

Это помогает понять, чем пользуются игроки, и развивать приложение. Без согласия эти данные не отправляются. Отозвать согласие можно в Настройках («Статистика для автора»), неотправленные данные при этом удаляются.

5. Как передаются данные. Данные из п. 3 и п. 4 передаются по защищённому соединению через сервис Google Apps Script (Google LLC) в Telegram-бот автора (Telegram FZ-LLC). Они не продаются, не используются для рекламы и не передаются другим лицам.

6. Что приложение не собирает. Контакты, геолокацию, файлы и фото с устройства (кроме снимков, которые вы сами выбрали для юнита, они остаются на устройстве), рекламный идентификатор, номер телефона, e-mail, данные аккаунтов.

7. Обращения к другим сервисам. Для работы приложение загружает открытые данные и страницы, не передавая личных данных: файлы правил и обновления приложения (GitHub, Яндекс Диск), новости (RSS сайтов о Horus Heresy, Google News, Reddit), перевод текста правил (Google Translate, передаётся только переводимый текст правил), поиск картинок для юнитов (Google, передаётся только название юнита). Эти сервисы видят ваш IP-адрес как при обычном открытии сайта и обрабатывают его по своим правилам. Ссылка на поддержку автора ведёт на Boosty.

8. Хранение и удаление. Полученные сообщения хранятся в Telegram автора. Чтобы удалить ваши данные, напишите на igorkisin@yandex.ru и укажите код LR-XXXXXX из Настроек → «Поддержавшие».

9. Дети. Приложение не предназначено специально для детей и не собирает данные детей умышленно.

10. Изменения. Политика может обновляться; актуальная версия всегда по этой ссылке и в Настройках приложения.
