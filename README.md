# Liber Rosterum — полная веб-версия

Ростер-билдер Horus Heresy 3.0 в браузере: https://rogienisick.github.io/liber-rosterum-web/

Каталоги BSData ([BSData/horus-heresy-3rd-edition](https://github.com/BSData/horus-heresy-3rd-edition)) загружаются при первом запуске и кешируются на устройстве. Без сети и без кеша открывается без фракций.

Работает: ростеры, юниты, умный ростер не перенесён; битва, фото, импорт/экспорт, библиотека — в разработке.
