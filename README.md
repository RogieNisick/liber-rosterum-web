# Liber Rosterum — веб-версия

Ростер-билдер Horus Heresy 3.0 для iPhone и любого браузера: https://rogienisick.github.io/liber-rosterum-web/

Откройте в Safari → «Поделиться» → «На экран „Домой“». После первой загрузки данных BSData работает офлайн.
Данные: [BSData/horus-heresy-3rd-edition](https://github.com/BSData/horus-heresy-3rd-edition).
